# Tech Stack Inicial (Draft)

- **Banco de Dados**: PostgreSQL (Supabase / RDS)
- **Backend**: NestJS (TypeScript) ou Express
- **Frontend**: Next.js (React)
- **Vídeo**: SDK do Twilio Video ou Agora.io
- **Pagamentos**: Stripe
- **Autenticação**: NextAuth / JWT Custom com RBAC
- **Hosting**: Vercel (Front) + Railway/AWS (Back)
